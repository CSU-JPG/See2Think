**Step 2 (Code):**

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import matplotlib.image as mpimg
import numpy as np
from scipy.ndimage import label, center_of_mass
from scipy.spatial import ConvexHull

# 1. Re-acquire points (Self-contained logic)
image_path = "image_path"
img = mpimg.imread(image_path)
if img.ndim > 2:
    gray = np.mean(img[:,:,:3], axis=2)
else:
    gray = img
binary = gray < 0.5
labeled, n = label(binary)
points_yx = np.array(center_of_mass(binary, labeled, range(1, n + 1)))
points_xy = points_yx[:, ::-1]

# 2. Compute Hull
hull = ConvexHull(points_xy)

# 3. Plot
fig, ax = plt.subplots()
ax.imshow(img)
for simplex in hull.simplices:
    ax.plot(points_xy[simplex, 0], points_xy[simplex, 1], 'c-')
plt.savefig('output.png')
```

Visual Observation: The plot from Step 2 clearly displays the cyan convex hull polygon enclosing the points.

**Final Answer:**
