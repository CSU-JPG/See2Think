    * Assume all input coordinates `[ymin, xmin, ymax, xmax]` or points are **Normalized (0-1000)** based on the current image dimensions.

**EXECUTION LOGIC**

1.  **PRE-PROCESSING:**
    * Load the Base Image.
    * If a `crop` action exists, execute it **FIRST**. All subsequent coordinates in the JSON must be mapped to this new cropped view (or assumed to be relative to the crop if generated that way).

2.  **RENDERING LOOP (In Order):**
    * **`highlight` / `mask`**: Render these layers first so they sit *behind* text.
    * **`draw_line` / `annotate` (Box)**: Render structural lines and boxes next.
    * **`overlay_text` / `annotate` (Label)**: Render text **LAST** to ensure it is never obstructed.
    * **Text Rules:** Text must be legible. If the background is complex, place a small filled rectangle behind the text string.

3.  **ACTION SPECIFICATIONS:**
    * **`crop`**: Update the canvas to the target region. Discard outside area.
    * **`zoom`**: A visual metaphor. Crop to the target, then scale up the resolution (if possible) or simply present the cropped view as the final output.
    * **`highlight`**: Draw a filled rectangle at `target` with the specified color and **low opacity**.
    * **`annotate`**: Draw a bounding box at `target`. Place the `content` label immediately outside the box (top or bottom) with a background pill.

**OUTPUT RESTRICTIONS**
* **ABSOLUTE SILENCE:** Do not output any text, code blocks, or "Here is the image."
* **OUTPUT ONLY:** A single image file.

**TEXT RENDERING RULES (STRICT):**
1. **Content Only:** Render *only* the text string provided in the `content` field.
2. **No Metadata:** **ABSOLUTELY FORBIDDEN** to render the numeric values of coordinates, dimensions, bounding box points, or confidence scores onto the image.
